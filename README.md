# Personal Homepage

This repository contains a static GitHub Pages homepage for Hancheng Hao and the RockFracPro research software.

## Files

- `index.html` - homepage content and page structure
- `assets/styles.css` - responsive visual design
- `assets/script.js` - mobile navigation and footer year
- `assets/profile.jpg` - personal portrait
- `assets/rockfracpro-avatar.jpg` - RockFracPro avatar
- `assets/paper-media/` - selected images extracted from the provided manuscript
- `assets/publications/` - renamed PDF copies for stable website links

## Customize

Replace the contact links in `index.html` with your preferred email, GitHub profile, Google Scholar, or institutional page.
